# OmniPitch System Architecture & Agentic Design

## 1. Overview & Core Philosophy
OmniPitch translates streaming synthetic football match events into explainable tactical intelligence and real-time storytelling. Every tactical deduction and narrative generated by an agent must be backed by verifiable event evidence IDs (e.g., `EVT-0042`), guaranteeing zero hallucinations and enterprise-grade reliability.

---

## 2. Five-Stage Pipeline

```
  Stage 1: INGEST
    └── MatchSimulationEngine / Azure Event Hubs (JSON event stream)
  
  Stage 2: INTERPRET
    └── Statistical aggregations (pass completion rate, speed tracking, distance covered)
  
  Stage 3: EXPLAIN
    └── Tactical indices:
        • Control vs Chaos Index (0.0 to 1.0)
        • Defensive Pressure Index (0.0 to 1.0)
        • Game Rhythm Tempo ('structured-possession', 'frantic-transition', etc.)
  
  Stage 4: RENDER
    └── Broadcast JSON Overlay Feeds (synchronized timecodes, player tags, shot maps)
  
  Stage 5: PERSONALIZE & LOCALIZE
    └── Viewer Persona Adapters (Tactical Analyst vs Casual Fan, club focus, multi-language)
```

---

## 3. Multi-Agent Ecosystem (Microsoft Foundry & Agent Framework)

### Agent Roles:
1. **Orchestrator Agent**:
   - Manages state machine and event dispatching.
   - Monitors latency; triggers rule-based fallback if model response exceeds SLA threshold (300ms).

2. **Tactical Analyst Agent**:
   - Analyzes trends over sliding 5-minute windows.
   - Identifies tactical momentum shifts, pressing triggers, and transition vulnerabilities.

3. **Broadcast Narrator Agent**:
   - Synthesizes tactical insight into punchy, broadcast-ready commentary and milestone alerts.

4. **Grounding Verifier Agent**:
   - Cross-references generated claims against actual raw event data using referenced `event_id` citations.
   - Rejects ungrounded statements, triggering immediate correction or fallback to deterministic templates.

5. **Personalization & Localization Agent**:
   - Tailors vocabulary, tone, and focal points:
     - *Analyst*: Advanced metrics, pass difficulty, line-breaking efficiency, zonal dominance.
     - *Fan*: Dramatic highlights, player milestone alerts, simplified excitement metrics.
   - Multi-language generation (English, Italian, Spanish, German, etc.).
